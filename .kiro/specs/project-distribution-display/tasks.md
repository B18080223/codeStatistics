# 实施计划：项目分布展示增强

## 概述

创建新的 `ProjectDistribution.vue` 组件替换现有的 `ProjectPieChart.vue`，增加数据表格、视图切换、空数据状态、饼图中心汇总、"其他"类别合并、响应式布局和加载骨架屏功能。所有变更均为前端实现，不涉及后端 API 修改。

## 任务

- [x] 1. 创建 ProjectDistribution.vue 组件基础结构
  - [x] 1.1 创建 `frontend/src/components/gitlab-stats/ProjectDistribution.vue` 组件文件
    - 定义 props 接口：`data: ProjectCommitData[]`、`loading?: boolean`
    - 定义内部状态：`viewMode` ref（`'chart' | 'table'`，默认 `'chart'`）、`hoveredRowIndex` ref
    - 实现计算属性：`totalCommits`（总提交次数）、`sortedData`（按提交次数降序排列）、`tableData`（带百分比占比）、`chartData`（超过 10 个项目时合并"其他"）
    - 定义内部类型 `ProjectTableRow`（扩展 `ProjectCommitData`，增加 `percentage` 字段）
